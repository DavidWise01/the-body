A grid, an atom's shells, and a binary register are the **same object in three costumes** — different ways to finitely address one pile of states. The invariant underneath is a single index, **`n`**. This is `n`, rendered three ways at once:

- **THE GRID** — base-10, `10×10×10 = 1000`, spatial. *(you can see it.)*
- **THE ATOM** — shells filling `2n²` (2, 8, 18, 32 …), quantized, physical. *(the d-subshell really does hold 10 — your "10 rings.")*
- **THE BITS** — binary, 10 bits, `2¹⁰ = 1024`, informational. *(the densest costume.)*

Move `n` and the one spark lights all three. Click the bits to flip them; ◀ ▶ or the slider to step; **walk** to auto-advance.

## The point (and the seam)
The costume is never the body. The grid wants **1000** (10³), the bits want **1024** (2¹⁰), the atom fills **2n²** per shell — three shapes that **miss each other by 24** and never agree on a waist size. (That near-miss, `2¹⁰ ≈ 10³`, is exactly why a "kilobyte" is 1024 but everyone says 1000.) What's invariant is only the **count, `n`**. Each costume is a faithful image *and* a quiet distortion — so you pick the one that does the job: **bits** for density, **shells** for physical levels, **grid** to see it.

## Honest: not emergent
This is a **representation demo, not a physics claim and not an emergent system.** It's a deterministic mapping `n → three views` — no dynamics, nothing measured, no ACI. The atom view is a **muse** (real shells fill 2n², split into s/p/d/f), not a map of anything. The repo carries `.attribute` / `.1099` provenance only.
